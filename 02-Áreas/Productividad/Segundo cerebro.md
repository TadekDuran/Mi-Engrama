# Segundo cerebro

Responsabilidad continua: sostener **Mi-Engrama** como una base de conocimiento que acumula, en lugar de una carpeta donde la información se dispersa. No tiene fecha de cierre. Tiene un estándar que se mantiene o se pierde.

El área responde a una pregunta que no termina nunca: *¿puedo encontrar y usar lo que ya leí?*

## Estándar de mantenimiento

La bóveda está sana cuando se cumplen estas cinco condiciones:

- [ ] Toda fuente ingerida tiene al menos una página de síntesis que la cita.
- [ ] El `_index.md` de cada tema lista todas sus páginas.
- [ ] El `_log.md` de cada tema registra la última ingesta.
- [ ] Ninguna página de `Síntesis/` es huérfana: todas se alcanzan desde el índice.
- [ ] No hay enlaces `[[...]]` rotos ni páginas con `estado: revisar` vencidas.

Una condición incumplida no es un desastre: es trabajo pendiente ya identificado.

## Rutina

| Cuándo | Qué |
|---|---|
| En cada ingesta | El flujo de siete pasos descrito en [[README]] |
| Una vez por semana | Vaciar `00-Inbox/`: clasificar o archivar |
| Una vez por mes | Lint: huérfanas, contradicciones, `estado: revisar` |

## Qué cuenta como avance

No es la cantidad de notas. Es:

1. Una pregunta que se responde leyendo el índice y bajando a dos o tres páginas.
2. Una fuente nueva que **modifica** páginas existentes en lugar de crear una nota aislada.
3. Cada vez menos tiempo entre "quiero saber X" y la respuesta.

Si el número de notas crece y el tiempo de respuesta no baja, se está acumulando, no sintetizando.

## Límites

Esta área no es el proyecto. El proyecto construye la bóveda; el área la mantiene viva.

- Un área sin proyecto produce mantenimiento sin dirección.
- Un proyecto sin área produce una bóveda abandonada en cuanto el proyecto se cierra.
